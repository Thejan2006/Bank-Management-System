# Bank Management System API

A secure and scalable banking backend built using Node.js, Express.js, MongoDB, and JWT Authentication.

## Features

- User Authentication
- JWT Authorization
- Account Management
- Deposit Money
- Withdraw Money
- Transfer Money
- Transaction History
- Admin Dashboard
- RESTful API

## Technologies

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- dotenv
